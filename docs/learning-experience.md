# 学习体验设计

本站以选词书、主动回忆、答后反馈和错词再练为核心。使用现有 HeroUI / HeroUI Pro 组件和配色；其他产品仅参考公开说明中的学习方式，不复用其词库、插画或界面素材。

## 入口与阶段

- 首页和词书库使用后端聚合，不下载整书来计算进度。词条、收藏每页 50 项，服务端搜索筛选；换词书重置搜索和状态。stage1 显示“学习中”，不会混入“未学”。
- 每轮新词数量可直接输入 1–500，约束每组上限而非当天封顶。接口最多 200，浏览器每组最多 min(100,设置值)；完成后可继续，新组重新取未完成词，不累计限制多组总数。
- 新词每词完成“认识词义 → 回忆英文”。任一步答错只重置该词，排到待练词之后，重练不限。两步通过才掌握；阶段和 revision 保存于后端，退出可续学，减小每轮数量也先取学一半的词。
- 待巩固为独立标记，可同时属于学习中。速刷入口使用真实 sprintCount，排除已掌握和待巩固。从详情开始练习前保存当前词书，单纯浏览不切换。
- 到期计数在页面可见时定期刷新，重新聚焦也更新；进行中的题目保持本轮快照，避免刷新中途换题。

## 主动回忆与答后反馈

- 中译英答前隐藏音标、例句和发音；拼写题直接聚焦输入框。`F` 发音，`1–4` 选项，`Enter` 确认拼写或继续；输入框不截获普通输入，长按不连续作答。
- 使用最多 200 个轻量候选，预先规范化词性、释义和拼写，再有界抽样，避免整书逐题复制洗牌。常见 a.、ad.、vt.、v.t. 等参与相同规范化。
- 共享规范化义项的候选不互作干扰项，不宣称推断所有真实同义词。无有效干扰项时退回拼写并提示首字母、字符数；有 2／3 个有效选项也可出题。新词 stage0 始终先认识词义，必要时仅展示真实的单个选项。本组中规范化**完整释义相同**的英文可作为拼写等价答案，不接受仅共享一个义项的任意词。
- 作答后收起干扰项，保留明确反馈与可展开选项；下一题固定底部，正文预留空间，阅读时长由用户决定。保存确认前不前进，换词恢复阅读位置，动画遵循减少动态效果偏好。
- 到期复习和巩固保留首轮评分、一次本地纠错，纠错不重复提交或改复习安排。收藏按词控制保存，确认后同步相关缓存，重开队列不回退旧星标。

## 临考速刷

速刷突出当前词、音标、发音和“不会／不确定／会”。未揭义选“会”直接掌握；“不会”保留原记忆。选“不确定”才显示释义，此后“会”进入待巩固，“不会”回不会列表。

- 三个按钮保留固定槽位；揭义后中槽显示“已看释义”，另外两键不变宽移位。释义独立滚动，操作区保持可触及；换词恢复页面和释义滚动。
- `1` 不会、`2` 或空格揭义、`3` 会、`F` 发音；聚焦按钮时空格保留原生激活，不额外揭义。
- 每批最多 100 词，非 learn 模式按词 ID 游标继续。不会词仅显式“再刷本组不会的”时重返，不自动循环；页面进度以当前组为准，接口 total 不是跨批固定总数。
- 最近一次本地确认判断可撤销。服务端以原事件时间限 120 秒，且同词无后续练习／内容更新才恢复；其他标签页新进度不能被旧撤销覆盖。成功后才回退本组汇总。
- 撤销保留历史标记但排除练习统计；重试幂等。超时、后续变化明确提示；撤销结果未知时暂停新判断并确认同事件，不能假装已撤销。

## 网络恢复与账号

- 保存期间始终可退出，取消本地等待不代表服务端未保存。待确认操作按用户、词书、模式暂存当前标签页 sessionStorage，重入先确认原 eventId，再读当前队列；不跨账号重放。
- 请求默认 15 秒确认超时；网络失败重试同次选择，内容／阶段／删除冲突可按当前进度恢复。撤销结果未知也保留待确认记录。浏览器存储受限时不能保证离开后恢复记录，当前页面仍可重试。
- 切账号通知其他标签页、取消旧请求、清理身份缓存并重挂载；写入再以 X-Word-User-ID 与 Cookie 核对。未及时收到通知的旧标签页也会被 SESSION_CHANGED 拒绝。
- 注册入口直接打开注册模式，访客注册保留原身份和进度。正式登录不依赖访客初始化，已登录正式账号有明确退出后注册入口；管理员落到首个启用模块。
- 访客不是永久可恢复账号。会话活跃续期与浏览器协调限制见[API 合同](api.md#身份与会话)；清理 Cookie、会话到期或换设备后，应通过已注册账户恢复进度。

## 编辑与统计

- 设置、词书、导入、导航草稿按用户与资源隔离，暂存当前标签页。保存中冻结字段，脏弹窗提供保留草稿或丢弃；刷新或关闭标签页时触发浏览器未保存提示，站内换页后可从当前标签页恢复草稿。存储失败明确告知，不声称草稿已安全保存。
- 设置只提交相对原 baseline 变更的字段，服务端 PATCH 只写提交列。导航携带读取版本，别人已保存则保留草稿并提示冲突。
- 导入省略音标／例句字段保留原值，显式空字符串清除；示例不能覆盖非空草稿。坏项给序号、词、字段，整批失败不部分写。实质内容变化使旧题失效，同内容不制造版本变化。
- “今日已练习”按 UTC 日期、所有模式词 ID 去重，activity 为真实尝试次数；不把它与每轮上限比较成每日新词完成率。撤销事件排除，单阶段答对不提前算掌握。
- 早期已删词且原 ID 丢失时，迁移按历史答案生成独立占位，保留记录但不能精确恢复同词去重；这部分历史去重词数可能偏高。

上述为实现与接口约定。集中浏览器、最终镜像及远端交付状态见[审计修复台账](audit-remediation.md)，本页不替代运行验证证据。
